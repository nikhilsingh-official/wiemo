# Offline Nuxt Docs

This folder is a local copy of the official Nuxt framework docs from:

https://github.com/nuxt/nuxt/tree/main/docs

Downloaded from commit `5b3e51a` on 2026-08-05.

## Search

From the project root:

```bash
rg "useAsyncData" offline-docs/nuxt
rg "queryCollection" offline-docs/nuxt
rg "route middleware" offline-docs/nuxt
```

## Browse

Start with:

- `offline-docs/nuxt/README.md`
- `offline-docs/nuxt/1.getting-started/`
- `offline-docs/nuxt/3.guide/`
- `offline-docs/nuxt/4.api/`

The files are Markdown and YAML source files from the docs site, so they can be read directly in an editor without a dev server.
