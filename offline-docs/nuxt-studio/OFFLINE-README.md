https://github.com/nuxt-content/nuxt-studio/tree/main/docs

```bash

rg "media" offline-docs/nuxt-studio
rg "auth" offline-docs/nuxt-studio
```

The Markdown files are copied from `docs/content`. Referenced screenshots and media assets are under `offline-docs/nuxt-studio/public`.
