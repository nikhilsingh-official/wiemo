# Bundled assets

Place assets here when they are imported by JavaScript, Vue, or SCSS and should
be tracked, fingerprinted, and potentially optimized by Nuxt's Vite build.

Use `public/` instead when application code needs a stable runtime URL. The
current GLB models and font files use stable `/models/...` and `/fonts/...` URLs,
so they belong in `public/models` and `public/fonts` respectively.
