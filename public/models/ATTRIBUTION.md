# 3D model credits

The models in this directory are distributed in binary glTF (`.glb`) format.
They are used as source geometry for the website's particle morph animation;
their original materials and textures are not rendered.

## Active hero sequence

The active order and presentation metadata are defined in `app/hero/stages.ts`.

### SpiralGalaxy.glb

- **Model:** Project-authored spiral galaxy with two arms and a galactic core
- **Generator:** Three.js `GLTFExporter` r185
- **License:** Project-owned original asset; all rights reserved
- **Usage:** Particle-sampled opening stage of the hero sequence

### EarthContinents.glb

- **Geometry:** Project-generated 192 × 96 segment sphere, partitioned into land
  and ocean surfaces using [Natural Earth 1:10m land polygons](https://www.naturalearthdata.com/downloads/10m-physical-vectors/)
- **Land data:** Natural Earth contributors
- **License:** [Public domain](https://www.naturalearthdata.com/about/terms-of-use/)
- **Downloaded:** 2026-07-29 (Natural Earth Vector repository)
- **Modification:** Coastline polygons classify the triangles of a smooth sphere.
  Land uses controlled sampling-density and modest brightness metadata while
  retaining the same global particle color; there are no overlapping layers.
- **Generated by:** `scripts/generate-earth-model.mjs`

### Human.glb

- **Model:** [MakeHuman HM08 base mesh](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj)
- **Creator:** MakeHuman Community
- **License:** [CC0 1.0 Universal](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md)
- **Downloaded:** 2026-07-29
- **Modification:** Retains only the continuous `body` group. Helper clothing,
  joint markers, eyes, teeth, tongue, and hair are excluded before geometry-only
  GLB export.
- **Generated by:** `scripts/generate-human-model.mjs`

### DNA.glb

- **Model:** [Canonical 1BNA ribbon](https://3d.nih.gov/entries/18183?version=2)
- **Creator:** NIH 3D workflows using RCSB PDB 1BNA structure data
- **License:** [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Downloaded:** 2026-07-29
- **Variant:** `1bna_4-ribbon-vis_NIH3D.glb`; geometry-defined ribbons and
  nucleotides with no texture dependency
- **Modification:** Rotated so the helix axis is vertical, stripped to position
  geometry, and tagged to preserve ribbon sampling density
- **Generated by:** `scripts/generate-dna-model.mjs`

### Fullerene.glb

- **Model:** [Fullerene C60](https://3d.nih.gov/entries/3839)
- **Creator:** abduljabar; generated by NIH 3D workflows
- **License:** Public Domain
- **Downloaded:** 2026-07-29
- **Variant:** Ball-and-stick with standard colors (`Fullerene-bas-color-print_NIH3D.glb`)

### CmsCollision.glb

- **Composition:** CMS electromagnetic calorimeter barrel with two project-authored particle spheres approaching its centre
- **Source model:** [CMS electromagnetic calorimeter barrel (`EcalBarrel3D_V2.glb`)](https://github.com/cms-outreach/ispy-webgl/blob/master/geometry/gltf/EcalBarrel3D_V2.glb)
- **Creator:** CMS Outreach / iSpy WebGL contributors
- **License:** [MIT](https://github.com/cms-outreach/ispy-webgl/blob/master/LICENSE)
- **License notice:** `CMS-ISPY-LICENSE.txt`
- **Downloaded:** 2026-07-29
- **Generated by:** `scripts/generate-collision-model.mjs`
